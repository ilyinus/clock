# Спецификация: учебные стрелочные часы

## Задача

Ребёнок учится соотносить положение двух стрелок с записью времени. Взрослый может выставить время и убрать цифровую подсказку, а также свободно перемещать стрелки для объяснения.

## Решение

Одна локальная страница с крупным центральным циферблатом. Под ним находится поле `ЧЧ:ММ` и переключатель его видимости. Стрелки захватываются указателем и вращаются. Переключатель синхронизации управляет связью стрелок. Отдельно выбираются три разметки часов и показ минут по окружности.

## Истории и приёмка

| Метка | История | Приёмка |
|---|---|---|
| R01 | Ребёнок видит часы и может определять время по стрелкам | Циферблат и управление понятны без инструкции; после скрытия поля цифровой ответ не виден |
| R02, R03, R04 | Пользователь открывает `index.html` прямо с диска | Нативные HTML, CSS, JavaScript; нет фреймворков, сборки, сетевых запросов или серверных зависимостей |
| R05, R06 | На странице видны центральный циферблат и две разные стрелки | Часовая короче и шире минутной; центр и деления различимы |
| R07 | Взрослый вводит `ЧЧ:ММ` под циферблатом | Корректный ввод от 00:00 до 23:59 задаёт обе стрелки; 12:00 и 00:00 указывают вверх |
| R07.1 | Ввод ошибочен или неполон | Поле сохраняет введённое, показывает понятную ошибку; стрелки не меняются до корректного ввода |
| R08 | Взрослый скрывает и возвращает цифровое поле | Скрываются поле и его подпись; положение стрелок остаётся прежним; управление доступно с клавиатуры |
| R09 | Взрослый тянет любую стрелку мышью | Захват происходит на видимой стрелке, движение следует за указателем вокруг центра и завершается при отпускании даже вне циферблата |
| R09.1 | Касание или прерывание перетаскивания | Pointer Events позволяют вести стрелку пальцем; отмена указателя завершает жест без зависшего состояния |
| R10 | В синхронном режиме вращается минутная стрелка | При переходе через 12 часовая плавно проходит соответствующую долю часа, в обе стороны; поле показывает согласованное время, если видно |
| R10.1 | В синхронном режиме вращается часовая стрелка | Минутная меняется согласно доле часа, включая переход через 12 |
| R11, R12 | В независимом режиме любую стрелку можно поставить произвольно | Вторая стрелка не движется, позиции могут быть несогласованными; цифровое поле не подменяет такое положение ложным временем |
| R11.1 | Режим переключён обратно на синхронный | Текущая минутная стрелка сохраняется, часовая приводится к ближайшему согласованному положению; статус сообщает об этом |
| R13, R14, R15 | Выбирается вариант разметки | Варианты: арабские 1–12, римские I–XII, без чисел; переключение не меняет стрелки |
| R16, R17 | Минутные подписи по контуру можно показать и убрать | Подписи 00, 05 … 55 видны по внешнему кольцу при включении, скрыты при выключении; остальная разметка остаётся |

## Решения по реализации

- Начальное время — 10:10: обе стрелки читаются и не закрывают друг друга. Это пример, не данные пользователя.
- Ввод цифрового времени — команда для выставления стрелок. По умолчанию поле видно и синхронизация включена. Предположение принято из формулировки «ввести время»; если пользователь уточнит смысл, спецификация меняется.
- При независимом перетаскивании поле очищается и получает пояснение, что стрелки поставлены независимо. Новый корректный ввод всегда снова выставляет согласованное время, но не меняет выбранный режим.
- Внутренние углы хранятся непрерывно при перетаскивании, чтобы переход через 12 не вызывал скачка. Внешне время ограничено 12-часовым циферблатом; цифровой ввод допускает 24 часа.
- Разметка и стрелки рендерятся в HTML/CSS/SVG без внешних ресурсов. Pointer Events и обычные элементы форм обеспечивают мышь, касание и клавиатурный доступ к настройкам.

## Вне рамок

Сохранение прогресса, счёт баллов, генератор упражнений и проверка ответов не запрошены. Состояние после перезагрузки страницы сбрасывается.

## Открытые места

Нет. Два вопроса брифинга временно закрыты рабочими решениями: цифровое поле выставляет стрелки; «без римских цифр» означает без чисел. Ответ пользователя будет иметь приоритет.
