## Что должно заработать

Ребёнок видит крупные стрелочные часы. Взрослый выставляет время цифровым полем либо вручную, скрывает подсказку, переключает синхронизацию, вид подписей часов и минутные подписи. Страница запускается прямо с диска.

## Из брифа, дословно

> «ребенок мог тренироваться определять время по стрелочным часам»
>
> «Оно должно запускаться без сервера, просто открыв файл index.html»
>
> «Стрелки можно передвигать просто мышкой, ухватившись за стрелочку и передвигая ее»
>
> «когда я прокручиваю минутную стрелку, часовая также двигается»
>
> «я могу поставить их как угодно, то есть выставив даже нереальное время, которого быть не может»
>
> «с обычными цифрами, с римскими цифрами, без римских цифр, с отображением минут, чтобы по контуру циферблата были написаны минуты, либо можно их убирать»

## Разделы спецификации

Вся таблица «Истории и приёмка», решения по реализации и `interfaces.md`.

## Критерии приёмки

- [ ] Открытие `index.html` через `file://` показывает аккуратный центральный циферблат с часовой и минутной стрелками, без сетевых зависимостей.
- [ ] Ввод корректного времени `ЧЧ:ММ` под часами устанавливает обе стрелки; неверный ввод не меняет стрелки и показывает ошибку.
- [ ] Поле времени можно скрыть и вернуть без изменения положения стрелок.
- [ ] Обе стрелки захватываются указателем; синхронное движение через 12 в обе стороны работает без скачков; независимый режим допускает несогласованные углы.
- [ ] Варианты подписей: арабские, римские, без чисел; отдельно видимы или скрыты минуты 00, 05 … 55 по окружности.
- [ ] Переход из независимого режима в синхронный восстанавливает согласованность, а цифровое поле никогда не показывает как текущее время положение независимых стрелок.
- [ ] `node --check script.js && node --test tests/clock.test.js` проходит с проверками граничного времени и геометрии перехода через 12.
