# Границы, решённые в спецификации

- index.html: семантика и порядок элементов. Сохраняются #show-minutes, #sync-mode, #show-time, input[name="dial-style"] со значениями arabic/roman/none, #clock-face, #hour-hand, #minute-hand и все SVG-группы.
- style.css: оформление цифр и доступных тумблеров, адаптивность, по одной опции в строке.
- script.js: drawDial() определяет позиции подписей; pointerAngle() согласован с SVG viewBox. createClockModel() и экспорт не меняются без необходимости.
- Швы проверок: node --check script.js && node --test tests/clock.test.js; браузер на 320 и широком экране, все стили часов с минутами, тумблеры, клавиатура и перетаскивание.

## Правила проекта
Без зависимостей и установки; index.html открывается локально. Положение стрелок хранится только в модели. Никаких изменений после прошлой сборки и незакрытых договорённостей нет.

## Реализовано
SVG viewBox 0 0 440 440, центр (220,220); drawDial, render и pointerAngle согласованы. Все ID и name сохранены.
