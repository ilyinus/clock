# Заметки по существующей реализации

- Циферблат — SVG `#clock-face`, viewBox `0 0 400 400`, центр `(200, 200)`, обод `r=184`; деления создаёт `drawDial()` в `script.js`: основные на радиусах 169–181, минутные 172–181. Часовые цифры сейчас на `r=120`, класс `.hour-number`; минутные подписи `00…55` — `r=152`, класс `.minute-number`. Для вынесения минутных подписей наружу обода менять радиус в `drawDial()` на значение за 184 с запасом на шрифт (подписи выровнены по центру); SVG уже имеет `overflow: visible`, но проверить, что панель/страница не обрезает край.
- Ключевая геометрия — `pointAt(radius, angle)`, использует центр `(200,200)`. Разметка SVG в `index.html` перечисляет слои: `#minute-marks`, `#hour-marks`, `#minute-labels`, `#hour-labels`; порядок позволяет меткам быть поверх делений. Увеличить часовые цифры и приблизить к делениям можно через `.hour-number` (сейчас `font-size:18px`) и радиус `pointAt(120, ...)`; внутренний край основных делений начинается на `r=169`, значит запас до цифр сейчас около 49 SVG-единиц.
- Настройки в `index.html`: набор стилей — `input[name="dial-style"]` внутри `.choice-row`; оставить radio-кнопками, текущая визуальная кнопка строится `.choice-row span`, состояние через `:checked + span` и фокус `:focus-visible + span`. Три переключаемые настройки — `#show-minutes`, `#sync-mode`, `#show-time`; обработчики `change` уже привязаны к ним. Для внешнего вида iPhone-тумблеров достаточно CSS для `input[type=checkbox]` и соседних/обёрточных элементов; текущая разметка toggle полей — `.toggle-row > legend` и `.toggle-content`.
- Настройки — `.settings` grid 2 колонки (на узком экране 1), каждый `fieldset` сейчас содержит одну опцию; `.choice-row` раскладывает радиокнопки горизонтально. В новой спецификации каждая из четырёх настроек занимает свою строку; три варианта цифр остаются кнопками в одной группе. Сохранять `id`/`name` и их обработчики.
- Основные риски: новые размеры текста могут столкнуться с минутными подписями/делениями или выйти за визуальную рамку; SVG масштабируется до 410px на широком экране и 370px на мобильном. Псевдоэлементы тумблера требуют скрыть нативный чекбокс доступно, сохранить клавиатурный фокус и кликабельную подпись. Не менять модель: геометрия циферблата только отображает `clock.state`.
- Проверки после изменений: `node --check script.js && node --test tests/clock.test.js`; визуально открыть `open index.html`, проверить арабские/римские/без чисел, минутные подписи за ободом, тумблеры мышью/клавиатурой, мобильную ширину, четыре отдельные строки настроек (старая сетка из двух колонок заменяется). DOM-интеракции тестами `tests/clock.test.js` не покрыты.
