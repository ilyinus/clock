# Границы, решённые в спецификации

## Правила проекта

- Локальный `index.html` работает без установки и зависимостей.
- Положение стрелок хранится в `createClockModel()`; SVG только отображает модель.
- Цифровое время скрывается для независимого положения стрелок или выключенной синхронизации.

## Поверхности

- `index.html` владеет семантической разметкой `.settings`, четырёх блоков настроек и существующих `id` флажков и SVG-групп. Внешний контракт для `script.js`: `#show-minutes`, `#sync-mode`, `#show-time`, `input[name="dial-style"]`, `#minute-labels`, `#hour-labels`, `#hour-marks`, `#minute-marks` сохраняются.
- `style.css` владеет сеткой `.settings`, рамками `fieldset`/`legend`, положением флажков и текстовыми стилями SVG. Семантика и модель в CSS не меняются.
- `script.js:drawDial()` владеет радиусами часовых цифр, минутных подписей и делений в SVG viewBox `400×400` с центром `(200,200)`.
- `script.js:render()` и `applyTime()` владеют статусом после ввода времени; чистая `createClockModel()` остаётся источником положения стрелок.

## Проверка

- Единственная команда проверки: `node --check script.js && node --test tests/clock.test.js`.
- Один тестовый файл: `node --test tests/clock.test.js`.
- В браузере проверить все четыре рамки, одинаковую высоту первого ряда, переключение по заголовку, арабские и римские цифры с включёнными минутами и статус после ввода в независимом режиме.

## Ограничения для исполнителя

- Стек: локальные HTML, CSS и JavaScript; зависимости не добавлять.
- Не менять смысл модели времени, обработчики перемещения стрелок и существующие значения `id`/`name` управляющих элементов.
