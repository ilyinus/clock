# Границы, решённые в спецификации

## Правила проекта

- Приложение работает через `file://` без сервера, сборки и внешних библиотек.
- В пользовательском интерфейсе русский язык.
- Единственный источник положения стрелок — модель в `script.js`; DOM и SVG только отображают её.
- Зависимостей и шага установки нет. Запуск: открыть `index.html` напрямую.
- Проверка: `node --check script.js && node --test tests/clock.test.js` (исполнитель создаёт тесты и выносит чистую математику в доступный для Node модуль без зависимости от DOM).
- Отдельный тест: `node --test tests/clock.test.js`.
- Не добавлять фреймворки, CDN, шрифты или иные сетевые ресурсы.

## Модель времени и геометрия

- `clockState`: `{ hourAngle, minuteAngle, synchronized, dialStyle, showMinutes, showTime, independentPosition }`.
- `setTime(hours, minutes)` задаёт согласованные углы и очищает `independentPosition`.
- `rotateHand(kind, pointerAngle, previousPointerAngle)` применяет кратчайшее приращение угла, сохраняя направление при переходе через 0°.
- `getDisplayedTime()` возвращает `HH:MM` только для согласованного положения.
- Геометрия не читает оформление; форма не вычисляет углы напрямую.

## Представление

- `index.html` содержит циферблат, две стрелки, поле времени и настройки.
- `style.css` отвечает за центрирование, размер, контраст, адаптивность и указатели захвата.
- `script.js` создаёт числовые подписи и минуты в SVG, связывает события и обновляет вид.
- Статус и ошибки видны текстом и объявляются через `aria-live`.

## Проверка

- Проверка без сборки: открыть `index.html` как `file://` и проверить сценарии из спецификации.
- Проверка вычислений: переходы через 12 в обе стороны, независимое перемещение и ввод границ 00:00/23:59.

## Реализованные интерфейсы

- `createClockModel()` возвращает `{ state, setTime(hours, minutes), rotateHand(kind, pointerAngle, previousPointerAngle), getDisplayedTime(), setSynchronized(enabled) }`.
