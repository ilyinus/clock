# Изначальная задача

> Записано 2026-11-14. Текст задачи не редактируется — он эталон, с которым сверяется готовый результат. Всё, что сказано позже, дописывается в «Дополнения» ниже.

Мне нужно создать приложение для того, чтобы ребенок мог тренироваться определять время по стрелочным часам. Приложение должно быть на JavaScript, HTML, CSS, без использования каких-либо дополнительных фреймворков, типа React и так далее. Оно должно запускаться без сервера, просто открыв файл index.html. По функционалу приложения должен быть центральный циферблат со стрелками: часовая и минутная. Ниже должно быть поле, в которое можно ввести время обычными цифрами. Также нужно сделать опцию, чтобы поле со временем можно было скрывать. Стрелки можно передвигать просто мышкой, ухватившись за стрелочку и передвигая ее. Стрелки могут быть синхронизированы, то есть когда я прокручиваю минутную стрелку, часовая также двигается. Также можно их рассинхронизировать, сделать, чтобы они были несинхронными. То есть я могу поставить их как угодно, то есть выставив даже нереальное время, которого быть не может. Нужно сделать несколько вариантов циферблата: с обычными цифрами, с римскими цифрами, без римских цифр, с отображением минут, чтобы по контуру циферблата были написаны минуты, либо можно их убирать.
