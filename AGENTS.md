# Учебные стрелочные часы

Локальное приложение для ребёнка: изучение времени на стрелочном циферблате. Работает без установки и зависимостей; `open index.html` успешно открывает приложение.

## Команды

| Команда | Что делает |
|---|---|
| `node --check script.js && node --test tests/clock.test.js` | Проверить синтаксис и запустить 5 тестов (5 passed, 0 failed) |
| `node --test tests/clock.test.js` | Запустить отдельный файл из 5 тестов (5 passed, 0 failed) |
| `open index.html` | Открыть приложение локально без сервера и установки |

## Точки входа

- `index.html` — семантическая разметка циферблата и настроек; `script.js` подключён с `defer`. Сохранять `#clock-face`, `#hour-hand`, `#minute-hand`, `#show-minutes`, `#sync-mode`, `#show-time`, `input[name="dial-style"]` (arabic/roman/none), `#minute-labels`, `#hour-labels`, `#hour-marks`, `#minute-marks` и ID ввода времени.
- `script.js:createClockModel()` — модель времени, синхронизации и углов стрелок; экспортируется для Node.
- `script.js:drawDial()` — генерация делений и числовых подписей SVG.
- `script.js:render()` и `setStatus()` — отображение модели, цифрового времени и статуса.
- `script.js:applyTime()` — проверка и применение ввода `ЧЧ:ММ`.
- Обработчики в конце `script.js` — перетаскивание указателей, клавиатура и настройки.
- `style.css` — оформление SVG, настройки по одной опции в строке и доступные тумблеры.
- `tests/clock.test.js` — тесты чистой модели без DOM.

## Подводные камни

- Положение стрелок хранится в модели `script.js`; SVG только отображает её.
- `getDisplayedTime()` возвращает `null` без синхронизации или при независимом положении. `render()` очищает ввод при независимом положении; весь блок ввода скрывает только `#show-time`.
- DOM-код запускается только при наличии `document`, поэтому модель можно подключать в Node-тестах.
- SVG имеет `viewBox="0 0 440 440"`, центр `(220,220)`. Геометрия разметки, `pointAt()`, `render()` и `pointerAngle()` должна оставаться согласованной; минутные подписи расположены снаружи часовых на радиусе 199.
- Изменения разметки должны сохранять перечисленные `id`/`name`: на них опираются обработчики `script.js`.
- При проверке интерфейса смотреть отдельные строки настроек на ширине 320 и широком экране, тумблеры и переключение по заголовку, клавиатуру и перетаскивание, все три стиля с минутами и статус после ввода времени в независимом режиме.
- Независимая приёмка HEAD `33b3ef8`: чистый клон, синтаксис и 5 тестов прошли; Chrome headless открыл `file://` и сгенерировал циферблат. Это не проверка всех интерактивных сценариев.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Требование из `manifest.md` может снять только пользователь. Прерванную сборку продолжает «продолжи автопилот».

## Правка без автопилота

Сначала прочитай `.autopilot/PROGRESS.md` и изменения после последней сборки. После правки добавь строку в «Правки без автопилота» и сделай коммит с трейлером `Requirements: R##`, когда применимо.

## История git

| Вопрос | Команда |
|---|---|
| что правили после последней сборки | `git log --oneline "$(git log -1 --format=%h --grep='^Autopilot: сборка сдана')"..HEAD -- . ':(exclude).autopilot'` |
| всё, что делали ради требования | `git log --oneline --grep="R02"` |
| история файла | `git log --oneline -10 -- <файл>` |
| когда появился или исчез код | `git log --oneline -S "<фрагмент>"` |
| почему строка такая | `git blame -L <с>,<по> <файл>`, затем `git show <sha>` |

Заголовок `Autopilot: сборка сдана` пишет только автопилот.
