# Учебные стрелочные часы

Локальное приложение для ребёнка: изучение времени на стрелочном циферблате.

## Команды

| Команда | Что делает |
|---|---|
| `open index.html` | Открыть приложение без сервера |

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Требование из `manifest.md` может снять только пользователь. Прерванную сборку продолжает «продолжи автопилот».

### Правка без автопилота

Сначала прочитай `.autopilot/PROGRESS.md` и изменения после последней сборки. После правки добавь строку в «Правки без автопилота» и сделай коммит с трейлером `Requirements: R##`, когда применимо.

### История git

| Вопрос | Команда |
|---|---|
| что правили после последней сборки | `git log --oneline "$(git log -1 --format=%h --grep='^Autopilot: сборка сдана')"..HEAD -- . ':(exclude).autopilot'` |
| всё, что делали ради требования | `git log --oneline --grep="R02"` |
| история файла | `git log --oneline -10 -- <файл>` |
| когда появился или исчез код | `git log --oneline -S "<фрагмент>"` |
| почему строка такая | `git blame -L <с>,<по> <файл>`, затем `git show <sha>` |

Заголовок `Autopilot: сборка сдана` пишет только автопилот.
