# Учебные стрелочные часы

Локальное приложение для ребёнка: изучение времени на стрелочном циферблате. Зависимостей и установки нет.

## Команды

| Команда | Что делает |
|---|---|
| `open index.html` | Открыть приложение; запуск через `file://` не подтверждён проверкой |
| `node --check script.js` | Проверить синтаксис JavaScript (код завершения 0) |
| `node --test tests/clock.test.js` | Запустить 5 тестов модели времени (5 passed, 0 failed) |

## Точки входа

- `index.html` — разметка циферблата и элементов управления; `script.js` подключён с `defer`.
- `script.js:createClockModel()` — модель времени, синхронизации и углов стрелок; экспортируется для Node.
- `script.js:drawDial()` — генерация делений и числовых подписей SVG.
- `script.js:render()` и `setStatus()` — отображение модели, цифрового времени и статуса.
- `script.js:applyTime()` — проверка и применение ввода `ЧЧ:ММ`.
- Обработчики в конце `script.js` — перетаскивание указателей, клавиатура и настройки.
- `style.css` — оформление и адаптивная сетка.
- `tests/clock.test.js` — тесты чистой модели без DOM.

## Подводные камни

- Положение стрелок хранится в модели `script.js`; SVG только отображает её.
- Цифровое время скрывается для независимого положения стрелок или выключенной синхронизации.
- DOM-код запускается только при наличии `document`, поэтому модель можно подключать в Node-тестах.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Требование из `manifest.md` может снять только пользователь. Прерванную сборку продолжает «продолжи автопилот».

## Правка без автопилота

Сначала прочитай `.autopilot/PROGRESS.md` и изменения после последней сборки. После правки добавь строку в «Правки без автопилота» и сделай коммит с трейлером `Requirements: R##`, когда применимо.

## История git

| Вопрос | Команда |
|---|---|
| что правили после последней сборки | `git log --oneline "$(git log -1 --format=%h --grep='^Autopilot: сборка сдана')"..HEAD -- . ':(exclude).autopilot'` |
| всё, что делали ради требования | `git log --oneline --grep="R02"` |
| история файла | `git log --oneline -10 -- <файл>` |
| когда появился или исчез код | `git log --oneline -S "<фрагмент>"` |
| почему строка такая | `git blame -L <с>,<по> <файл>`, затем `git show <sha>` |

Заголовок `Autopilot: сборка сдана` пишет только автопилот.
