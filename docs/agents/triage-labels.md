# Статусы triage

В локальных задачах статус записывается строкой `Status:`.

| Роль | Значение | Смысл |
|---|---|---|
| needs-triage | needs-triage | Требуется первичный разбор |
| needs-info | needs-info | Ожидается дополнительная информация |
| ready-for-agent | ready-for-agent | Задача описана и готова для агента |
| ready-for-human | ready-for-human | Требуется выполнение человеком |
| wontfix | wontfix | Задача не будет выполняться |

Когда навык указывает роль triage, используй значение из таблицы.
Для изменения словаря отредактируй колонку «Значение».
