# Трекер задач: локальный Markdown

Задачи и спецификации хранятся в `.scratch/`.

## Структура

- Одна возможность — один каталог `.scratch/<feature-slug>/`.
- Спецификация — `spec.md` внутри каталога возможности.
- Каждая задача — отдельный файл `issues/NN-<slug>.md`.
  Нумерация начинается с `01`.
- Статус triage — строка `Status:` в начале задачи.
  Значения определены в `triage-labels.md`.
- Обсуждение дописывается в конец файла под заголовком `## Comments`.

## Операции навыков

«Опубликовать в трекере» — создать соответствующий Markdown-файл,
при необходимости создав каталог.

«Получить задачу» — прочитать указанный файл. Если передан только
номер, найти соответствующий файл в каталоге текущей возможности.
Если совпадений несколько, уточнить возможность.

## Wayfinder

- Карта исследования — `.scratch/<effort>/map.md` с разделами
  Notes, Decisions-so-far и Fog.
- Дочерняя задача — `.scratch/<effort>/issues/NN-<slug>.md`.
- `Type:` задаёт тип: research, prototype, grilling или task.
- Для задач Wayfinder `Status:` задаёт состояние работы:
  open, claimed или resolved. Эти значения относятся к Wayfinder,
  а не к статусам triage.
- Зависимости записываются строкой `Blocked by: NN, NN`.
  Задача разблокирована, когда все зависимости имеют статус resolved.
- Следующая задача — первая по номеру со статусом open
  и без незавершённых зависимостей.
- Перед началом работы сохранить `Status: claimed`.
- По завершении добавить ответ под `## Answer`, поставить
  `Status: resolved` и добавить краткий итог со ссылкой
  в Decisions-so-far карты.

## Связь с Autopilot

`.autopilot/` сохраняет требования, спецификации и историю сборок
Autopilot. Локальный трекер инженерных навыков находится в `.scratch/`.
При работе по требованию Autopilot указывай его R## в задаче.
