# Рефакторинг для удобства доработки

Статус: согласованы цели и ограничения; организация JavaScript ожидает подтверждения. Код приложения пока не менялся.

## Согласовано

- Поведение и внешний вид полностью сохраняются, включая маску ввода, независимые стрелки и живое время.
- Объём работы: JavaScript, HTML и CSS.
- Приложение по-прежнему открывается через `index.html` без сервера, установки и зависимостей.
- Код должен быть понятен человеку с базовым знанием JavaScript.
- Комментарии пишутся по-русски и объясняют причины неочевидных решений.

## Предложение к подтверждению

Сохранить один `script.js`, организовав его в понятные разделы: модель времени, построение циферблата, отображение, управление стрелками, ввод времени, живое время и настройки. Использовать небольшие именованные функции, развернуть сжатые строки и дать геометрическим величинам понятные имена.

Карта кода и проверки должны помочь следующему разработчику найти нужное место. Проверка включает существующие тесты модели и браузерные сценарии ввода, управления стрелками, режимов и настроек на узком и широком экране.
