# Живое время

Статус: обсуждение; реализация ещё не согласована полностью.

## Согласовано

- Источник времени — системные часы устройства, местное время.
- Управление — тумблер «Живое время» рядом с остальными настройками.
- При открытии приложения живое время выключено.
- При включённом живом времени появляется секундная стрелка, которая перескакивает раз в секунду.
- В этом режиме перетаскивание стрелок и ручной ввод времени заблокированы.

## Открытые решения

- Состояние учебных часов после выключения живого времени.
- Поведение настройки «Связанные стрелки» во время живого времени.
- Формат цифрового времени в этом режиме.
- Положение часовой и минутной стрелок с учётом секунд.
