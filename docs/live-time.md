# Живое время

Статус: решения согласованы по вопросам Q1–Q8; ожидается итоговое подтверждение перед реализацией.

## Согласовано

- Источник времени — системные часы устройства, местное время.
- Управление — тумблер «Живое время» рядом с остальными настройками.
- При открытии приложения живое время выключено.
- При включённом живом времени появляется секундная стрелка, которая перескакивает раз в секунду.
- В этом режиме перетаскивание стрелок и ручной ввод времени заблокированы.
- При выключении живого времени часовая и минутная стрелки остаются на текущих местах, секундная исчезает. Предыдущее положение учебных часов не восстанавливается.
- Настройка «Связанные стрелки» временно заблокирована; её значение сохраняется и снова действует после выключения живого времени.
- Цифровое время в живом режиме отображается в формате `ЧЧ:ММ:СС`; настройка «Показывать время» продолжает управлять его видимостью.
- Часовая и минутная стрелки учитывают секунды; все три стрелки обновляются раз в секунду и показывают согласованное системное время.
- Настройки подписей часов и минут остаются доступны.
